Bitrue is a centralized cryptocurrency exchange offering spot trading, USDT-margined and coin-margined perpetual futures, copy trading and a crypto wallet. It publishes public REST and WebSocket APIs for market data, account and order management, deposits and withdrawals, with HMAC-SHA256 signed requests, documented at www.bitrue.com/api-docs and in the Bitrue-exchange GitHub organization.

**Areas:** Company · Cryptocurrency · Exchange · Trading · Futures · Market Data · WebSocket

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Bitrue: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
